디자인과 코딩의 경계가 점점 사라지고 있습니다.

Wonder가 디자인 화면과 실제 코드를 연결하는 새로운 버전을 공개했습니다.

기존 프로젝트의 코드를 연결하면 실행 중인 앱 화면을 편집 가능한 디자인 요소로 바꿀 수 있는데요.

예를 들어 버튼이나 화면 구성을 디자인 도구에서 수정하고, 변경 사항을 다시 코드에 반영하는 방식입니다.

개인 Claude와 Codex 구독도 연결할 수 있어 별도의 AI 구독 없이 활용할 수 있습니다.

디자인을 만들고 개발자에게 전달하던 작업 방식도 달라질 것 같네요.
